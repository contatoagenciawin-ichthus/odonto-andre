# André Ávila — Site e Design System

Aplicação Next.js para site institucional, captação regional e design system.

- `/design-system`: biblioteca visual e componentes para aprovação.
- `/americana/proteses-dentarias`: landing page regional (estrutura inicial).
- `/caconde/odontologia-geral`: landing page regional (estrutura inicial).

## Desenvolvimento local

```bash
npm install
npm run dev
```

Nenhum workflow do GitHub Actions é configurado. O logotipo oficial deve substituir o espaço reservado em `public/brand/` quando o arquivo vetorial/transparente estiver disponível. Não utilizar as peças de referência como se fossem arquivos-fonte da marca.

Contato, CRO, endereço e alegações profissionais devem ser confirmados antes da publicação. A captação de dados e integrações estão fora deste protótipo visual.
